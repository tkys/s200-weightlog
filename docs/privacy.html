体重ログ (s200-weightlog)

プライバシーポリシー

最終更新日：2026年11月13日

「体重ログ」（以下「本アプリ」）は、Xiaomi Smart Scale S200 の計測値を、利用者自身の Mac で記録するための個人用ツールです。本アプリは利用者の Mac の中だけで動作し、開発者が運営するサーバーはありません。

扱う情報

  • 体重計から受信した体重と計測日時
  • 利用者がアプリに入力した日ごとのメモ・タグ、身長・目標体重などの設定

これらは利用者の Mac 上のデータベースに保存されます。

Google ユーザーデータの扱い

利用者が Google Drive 連携を有効にした場合に限り、本アプリは Google アカウントへのアクセスを求めます。

  • スコープ：https://www.googleapis.com/auth/drive.file のみ。本アプリが作成したファイルにだけアクセスでき、Google Drive 上のそれ以外のファイルを読むことはできません。
  • 使い方：上記の体重記録・メモを、利用者自身の Google Drive の「体重ログ」フォルダに、スプレッドシート・CSV・データベースのバックアップとして保存・更新します。古いバックアップの削除も、本アプリが作成したファイルに限られます。
  • 共有：Google ユーザーデータや体重記録を、開発者を含む第三者に送信・共有・販売することはありません。広告や分析にも使いません。
  • 保存：Google の認証トークンは利用者の Mac 上（アクセス権を本人のみに制限したファイル）にのみ保存されます。

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

アクセスの取り消しとデータの削除

  • Google アカウントのサードパーティ接続の管理から、いつでも本アプリのアクセスを取り消せます。
  • Google Drive に保存されたファイルは、利用者が Drive 上で自由に削除できます。
  • Mac 上のデータは、本アプリのフォルダにあるデータベースと .drive/ フォルダを削除すると消去されます。

Summary (English)

WeightLog is a personal tool that runs only on the user's own Mac. If Google Drive upload is enabled, it requests only the drive.file scope and uses it solely to create and update its own files (weight records, notes, database backups) in the user's own Google Drive. No Google user data is sent to the developer or any third party, or used for advertising or analytics. The OAuth token is stored only on the user's Mac. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account third-party connections page.
